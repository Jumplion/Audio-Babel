# `docs/components/` — Reusable HTML fragments

HTML partials loaded at runtime via
[`js/ui/loadFragment.js`](../js/ui/loadFragment.js) and injected into a page
container. See the [root README](../../README.md) for the site overview.

## Files

| File | Purpose |
| ---- | ------- |
| `result.html` | The result panel markup — index display, library position (with "Find in Library" action), metadata, cover art, and audio playback controls. Populated by [`js/core/resultDisplay.js`](../js/core/resultDisplay.js). |
