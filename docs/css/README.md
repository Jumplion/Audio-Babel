# `docs/css/` — Stylesheets

Styling for the static site, themed as a warm "library / record shop" (walnut
wood tones, brass-gold accents). See the [root README](../../README.md) for the
site overview.

## Files

| File | Scope |
| ---- | ----- |
| `site.css` | Global: CSS variables, base typography, theme, layout, and common components/utilities. Imported by every page. |
| `navbar.css` | The fixed top navbar ("wood-and-brass shop sign"). |
| `index.css` | Home page (`index.html`) — record-shop hero. |
| `browse.css` | Browse page (`browse.html`) — hierarchical navigation. |
| `search.css` | Search page (`search.html`) — card-catalog "drawers". |
| `result.css` | Result display components (used by `js/core/resultDisplay.js`): metadata, expandable sections, playback controls. |
| `about.css` | About page (`about.html`). |
